# Crafty Next.js

Premium handmade craft marketplace built with Next.js, React, Tailwind CSS, Framer Motion, and lucide-react.

## Scripts

- npm run dev
- npm run build
- npm run start
- npm run lint

## Structure

- src/app: Next.js app router entry points
- src/components: reusable storefront UI
- src/context: marketplace state and persistence
- src/data: craft product content and testimonials
